# NIHONGO

Starter aplikasi Flutter belajar Hiragana dan Katakana.

Fitur awal:
- 46 Hiragana
- 46 Katakana
- Flashcard
- Latihan menulis di layar
- Tema putih-emas
- Navigasi mobile

Jalankan:
flutter pub get
flutter run

Build APK:
flutter build apk --release

APK hasil build biasanya:
build/app/outputs/flutter-apk/app-release.apk
